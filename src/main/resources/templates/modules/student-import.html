Upload the spreadsheet

  1. Export the learner list from the old system to Excel, or download Lumora's template.
  2. Make sure the columns match the list on the right. Extra columns are ignored.
  3. In Excel choose File → Save As → CSV UTF-8 (Comma delimited).
  4. Upload the .csv file here.
Leave this ticked if you are uploading the same file again, or adding a second file after the first.

Columns

Needed

  • Admission number
  • First name and last name (middle name optional), or one Name column
  • Gender: Male / Female (or M / F)
  • Date of birth: 14/03/2012 or 2012-03-14
  • Form: Form 1 to Form 4 (or 1 to 4)
  • Stream: one of East,

Optional

  • Admission date, County
  • Guardian name and phone (both, or neither)
  • Guardian relationship: Mother, Father, Guardian…

Brothers and sisters with the same guardian phone number are linked to one guardian.
